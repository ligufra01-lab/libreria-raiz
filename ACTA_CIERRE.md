## 3. Alcance presentado

La propuesta de entrega para la feria prioriza las funcionalidades esenciales:

- Blog o sección de reseñas.
- Calendario o sección de eventos.
- Formulario de contacto con validación en el navegador.
- Página principal y navegación entre secciones.
- Repositorio documentado y publicación mediante GitHub Pages.

## 4. Decisiones de cierre simuladas

1. Mantener como prioridad las funciones esenciales para presentar la librería y sus actividades.
2. Dejar la integración de redes sociales como mejora posterior si no existe capacidad dentro del sprint.
3. Mantener la versión en inglés como funcionalidad opcional para una iteración futura.
4. Aplazar la producción e integración de podcasts para la versión 2.
5. Comunicar que el formulario implementado es una demostración del lado del cliente: valida datos en el navegador, pero no los envía ni almacena en un servidor.
